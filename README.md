# Exercise_Unit5_website

Este repositorio contiene una página web simple
Incluye archivos HTML y CSS básicos, además de prácticas con ramas, merges, etiquetas y GitHub Pages.

## Tecnologías utilizadas
- HTML
- CSS
- Git / GitHub

## Contenido del repositorio
- index.html – Página principal del sitio web
- styles.css – Archivo css
- logo.ppg – Imagen utilizada en la página
- .gitignore – Exclusión de archivos innecesarios

## Cómo abrir la página web
1. Descarga o clona el repositorio.
2. Abre el archivo index.html en cualquier navegador web.
